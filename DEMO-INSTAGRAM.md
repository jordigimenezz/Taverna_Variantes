# Sección de Instagram

La portada muestra cuatro publicaciones reales de @tavernavariantes. Cada miniatura es una imagen local de dist/assets/instagram/ que enlaza a la publicación original en una pestaña nueva.

Para cambiarlas, editar src/instagram-posts.json, sustituir las miniaturas y ejecutar npm run build.

La galería no se actualiza automáticamente, no usa credenciales y no carga scripts ni inserciones de Meta. Por eso no necesita consentimiento.
